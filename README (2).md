# noxcoredev.github.io

Portfolio for NoxCoreDev, published with GitHub Pages at https://noxcoredev.github.io

## Publish it
1. On GitHub, create a public repository named exactly `noxcoredev.github.io`.
2. Click **Add file → Upload files**, then upload `index.html`, `style.css` and the `assets/` folder.
3. Click **Commit changes**.
4. Go to **Settings → Pages**, set **Source** to *Deploy from a branch*, branch `main`, folder `/ (root)`, then **Save**.
5. Wait a minute or two, then open https://noxcoredev.github.io

## Edit it
Change the text in `index.html` (projects, about, contact). Colors are at the top of `style.css`.

## SEO (already included)
- `robots.txt` and `sitemap.xml`: tell Google which pages to index.
- JSON-LD `Person` and `WebSite` data in `index.html`: tells Google that NoxCoreDev is a developer and links the name to this site.
- Title, description, canonical link and social preview tags mention NoxCoreDev.

## After publishing (required for fast indexing)
1. Open https://search.google.com/search-console and add the property `https://noxcoredev.github.io`.
2. Verify it (the "HTML tag" method is easiest, or the file method).
3. In **Sitemaps**, submit `sitemap.xml`.
4. Use **URL inspection** on `https://noxcoredev.github.io/` and click **Request indexing**.
5. Put the link https://noxcoredev.github.io on your GitHub profile, and on any other accounts you use. Google follows these links.
